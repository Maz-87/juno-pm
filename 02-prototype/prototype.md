## What it demonstrates

This demonstrates an example of an 'Insight' tool that can be used by the PM Lead when preparing what to design/build/solve for in the upcoming sprint. It aims to remove the manual work required to sythesise feature requests manually by problem statements (rather than solution focused).

## Debrief

**What worked:**
- AI gave a great output with very little prompting on expected format
- Part of my prompt was for AI to ask any clarifying questions before proceeding
- AI successfully interated on the design and transposed it into a Notion style table (which was requested since this is one of the tools used by Juno)

**What broke / felt like a toy:**
- No links (since it is using simulated data)
- No ability to filter the table (eg. by source, customer etc) since the prototype isn't actually using Notion's native functionality
- Also unsure if hese accordion style grouping is possible within Notion (?)

**What I'd change next pass:**
- I would simplify the design to make it more digestable for the Lead PM. This could be done by being clearer on how the PM will use this tool.
